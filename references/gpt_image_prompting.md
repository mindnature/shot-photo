# GPT Image / Images 2.5 Prompting Guide

Shot Photo 默认主要服务 GPT Image / Images 2.5。

## 1. 总原则

Images 2.5 更适合“简洁但准确的摄影导演指令”，而不是穷尽式参数表。

优先写清楚：

1. 谁；
2. 在哪里；
3. 正在发生什么；
4. 摄影师以什么关系观察；
5. 一个核心构图亮点；
6. 一个核心光线或空间亮点；
7. 必要时一个真实摄影状态。

> 内部规划可以复杂，最终 Prompt 要短、准、留有模型发明空间。

## 2. Prompt Compression

后台可以规划：

```text
scene
moment
expression
wardrobe
shot size
lens
camera position
composition
foreground
lighting
palette
imperfection
observation relationship
subject scale
```

最终 Prompt 不需要逐项抄写。

一张图通常最多突出：

- 1 个动作瞬间；
- 1 个 Observation Relationship；
- 1 个构图亮点；
- 1 个光线 / 空间亮点；
- 0–1 个摄影缺陷。

每增加一句，都要真正改变画面，否则删掉。

## 3. Standard Prompt

```text
[画幅]真实生活摄影。
[主体]在[场景]，[进行中的瞬间]。
摄影师从[观察关系]记录，重点采用[一个构图亮点]。
现场是[一个真实光线来源]，[可选一个空间或真实感线索]。
避免影楼式精修、塑料皮肤和标准摆拍，保持可信生活摄影感。
```

通常约 100–240 个中文字。

## 4. Random Strong

Random Strong 要更短，让高层随机真正传到图像端。

```text
[画幅]真实手机 / 生活摄影。
一位[主体]在[随机子场景]，[进行中的动作]。
从[随机观察关系]抓到这一瞬间，画面重点是[一个构图亮点]。
光线来自[真实现场来源]。像偶然拍到的照片，不要标准人像模板。
```

通常约 70–180 个中文字。

## 5. Random Wild

Wild 只锁用户真正要求的内容。

```text
[画幅]真实生活摄影。
为[主体]在[宽泛场域]创造一张意外但可信的照片。
选择不常见但合理的子场景、观察距离和机位，捕捉未完成动作。
构图可以大胆，但必须物理上可拍到；光线来自真实环境。
不要商业写真感。
```

Wild 不要把所有随机结果重新写成硬约束。

## 6. Series Prompt — v0.8

系列模式读取 `references/series_entropy.md`。

Series 的 Prompt 目标不是“九张都稳定得一样”，而是：

> 身份连续，摄影关系高熵。

每张 Series Prompt 只需要：

1. 一句简洁身份 / 服装连续性；
2. 这一张的动作瞬间；
3. Observation Relationship；
4. 一个构图亮点；
5. 一个光线 / 空间线索；
6. 必要时一个 imperfection。

推荐模板：

```text
[画幅]真实生活摄影。保持与整组相同的人物身份、发型和服装，像同一次真实拍摄。
这一张：[主体]在[场景]，[进行中的动作]。
摄影师以[Observation Relationship]记录，采用[一个构图亮点]，人物尺度为[subject scale]。
现场保持[真实光线 / 空间线索]。
[可选：允许一个真实摄影缺陷]。
不要标准摆拍，不要把每一张都做成商业写真或旅游宣传片。
```

如果有参考人物图，优先依赖参考图维持身份，不反复写长篇五官描述。

## 7. Series Entropy 不要被 Prompt 抹平

Series 中不要九张都写：

```text
自然微笑
看向侧面
手抓包带
中距离平视
背景漂亮
```

Prompt 必须保留规划器分配的核心差异，例如：

- 同行朋友边走边拍；
- 从人物背后跟拍；
- 人群空隙抓拍；
- 从店内隔玻璃向外拍；
- 低机位动态；
- 人物小比例大环境；
- 前景遮挡；
- 背影离场。

但每张只突出其中最重要的 1–2 项，不堆满。

## 8. Background Text Suppression

这是 v0.8 的默认规则。

除非用户明确要求招牌文字清晰可读，否则背景文字只作为环境纹理：

```text
背景招牌只作为环境纹理，文字优先局部、模糊、被遮挡或裁切，不生成大段完整宣传文字。
```

尤其在古城、老街、旅游地、校园、市场等场景，不要为了证明地点反复生成：

- 完整地名；
- 店名；
- 旅游口号；
- “某某古城 / 某某特产 / 一杯某某”等 AI 式完整文案。

建立空间的少数镜头可以自然出现一个地点线索，其余镜头优先让空间本身说明地点。

## 9. Anti-Tourism-Poster

旅行系列不要让每一张都同时出现：

```text
地标 + 漂亮招牌 + 鲜花 + 灯笼 + 水渠 + 山景 + 完美阳光
```

一组真实旅行照片应该同时包含：

- 好看的建立空间镜头；
- 普通墙面或转角；
- 人群干扰；
- 半截门面；
- 阴影；
- 逆光；
- 路过抓拍；
- 局部环境。

“地点可信”优先于“地点元素堆满”。

## 10. Anchor Budget

### Standard

- Hard Anchors ≤ 4
- Soft Anchors ≤ 4
- Free Variables ≥ 4

### Random Strong

- Hard Anchors ≤ 3
- Soft Anchors ≤ 3
- Free Variables ≥ 6

### Random Wild

- Hard Anchors ≤ 2
- Soft Anchors ≤ 2
- Free Variables ≥ 8

### Series Strong Entropy

强锁：identity / wardrobe / place world / time window。

主动放开：camera / action / subject scale / composition / observation / foreground / imperfection。

## 11. 抽象词转译

“高级感”优先转成 1–2 项：色块克制、真实空间、动作克制、单纯光源、负空间。

“电影感”优先转成 1–2 项：明暗关系、摄影距离、未完成动作、现实光源、空间层次；不自动等于橙青调。

“抓拍感”优先转成：动作未完成、人物不服务镜头、摄影师不在标准正面位、边缘有真实环境关系。

“松弛感”优先转成：身体有重量和依靠、动作不展示、视线不服务镜头、构图不追求绝对对称。

## 12. Controlled Imperfection

真实感不等于统一加噪点。

单张默认 0–1 个；9 张系列建议只有 1–3 张明显使用：

- 轻微运动模糊；
- 边缘物体进入；
- 小范围自然过曝；
- 玻璃反射；
- 轻微倾斜；
- 前景遮挡。

真实感优先来自：

```text
动作 + 空间 + 摄影师位置 + 真实光线
```

## 13. 同一人物系列

只有用户明确要求“同一个人 / 一套写真 / 连续组照”时锁身份。

- 有参考图：参考图是身份主锚点；
- 无参考图：简洁重复同一人物身份、发型、年龄感与核心服装；
- 不每张重新描述一套五官；
- 不为了连续性把动作、机位和构图也一起锁死。

## 14. 参考图

用户给照片时优先提取：

- 人物占比；
- 摄影距离；
- 机位高度；
- 可能焦段区间；
- 前 / 中 / 后景；
- 光线方向；
- 主要色块；
- 动作阶段；
- 真实感来源。

Reference + Random：只锁 2–4 个最高置信 DNA。

Reference + Series：参考图主要锁人物身份和少量摄影 DNA；Series Entropy 仍负责让组照产生变化。

## 15. 最终检查

提交 Prompt 前问：

1. 摄影师为什么站在那里？
2. 为什么恰好在这一秒按快门？
3. 这张与整组上一张的摄影关系是否真的不同？
4. 我是否写了太多 Images 2.5 本来可以自己完成的细节？
5. 背景是否出现不必要的大段可读文字或“旅游宣传片套餐”？

前 3 项答不出来：摄影逻辑或 Series Entropy 不足。
第 4 项为“是”：删约束。
第 5 项为“是”：压低文字与景点元素。
