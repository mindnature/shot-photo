# GPT Image Prompting Guide

Shot Photo 默认只为 GPT Image 优化。

## 1. 核心原则

GPT Image 更适合完整、自然、关系明确的视觉语言。不要把摄影提示词写成逗号分隔的标签仓库。

优先写清楚：

1. 谁在画面里。
2. 人在哪里。
3. 正在发生什么。
4. 摄影师在哪里。
5. 人物和环境分别占多少画面。
6. 光从哪里来。
7. 哪些现实摄影缺陷可以保留。

## 2. 推荐 Prompt 结构

```text
[画幅与图片类型]
[主体身份与外观中真正重要的部分]
[场景、季节、时间]
[动作正在发生的瞬间]
[摄影师位置 + 景别 + 焦段]
[构图和人物在画面中的位置]
[前景 / 中景 / 背景关系]
[光线来源与明暗关系]
[克制的主色块]
[1-3个真实摄影状态]
[总体摄影约束]
```

最终必须合成为流畅自然语言，不要保留上述字段名。

## 3. 示例骨架

```text
9:16 竖幅真实生活摄影照片。一位短发中国女性在广州盛夏午后的老城区街边，刚从便利店推门出来，手里还拿着冰饮，走了两步后因为迎面热风短暂停住，抬手把吹乱的头发别到耳后。摄影师站在街对面，以 35mm 环境人像视角平视观察，拍摄膝上中景；人物偏在画面右侧，左侧保留一大块被阳光照亮的旧墙和街道空间。便利店玻璃门边缘形成轻微前景反射，人物没有看镜头。强烈夏日硬光从侧后方落下，白墙提供自然反光，画面以暖灰、奶白、少量绿色和肤色为主。保留轻微高光溢出和一点手持即时感，但人物面部和动作仍然自然可信。不要影楼感，不要过度磨皮，不要商业网红摆拍，不要把人物自动移到画面中央。
```

## 4. 少控制什么

避免过度规定：

- 每一根手指的位置
- 头部精确旋转角度
- 灯光精确到度数
- 同时指定过多摄影器材参数
- 每个背景物体的数量和位置
- 服装的所有材质、纽扣、褶皱与配饰
- 五六种摄影缺陷同时出现

用户真正需要控制的是视觉锚点，不是每个像素。

## 5. 抽象词要转译

### “高级感”

不要只写“高级”。转译为：

- 色彩控制在 3-4 个主色块
- 背景干净但不空洞
- 人物动作克制
- 光线来源单纯
- 构图有明显负空间

### “电影感”

不要默认橙青调。转译为：

- 明暗关系
- 人物与摄影师距离
- 未完成动作
- 现实光源
- 环境层次
- 叙事上的前一秒 / 后一秒感

### “抓拍感”

不要只写 candid。转译为：

- 动作未完成
- 人物没有准备好
- 摄影师位置不是正面标准位
- 边缘存在真实环境物
- 轻微不完美但主体仍清晰

### “松弛感”

转译为：

- 身体重量有依靠
- 动作不是展示姿态
- 视线不服务镜头
- 服装和场景具有生活合理性
- 构图不追求绝对对称

## 6. 负面约束写法

GPT Image 中不要写几十项 negative prompt。只保留会显著破坏目标的 3-6 项。

推荐：

```text
不要影楼感，不要标准网红摆拍，不要过度磨皮，不要塑料皮肤，不要无理由复杂背景，不要自动把非常规构图修正为居中人像。
```

根据具体任务删减，不要每张图机械复制同一串。

## 7. 同一人物系列

如果用户要求同一人物连续生成：

- 每组重复人物身份中最稳定的 3-5 个识别点。
- 不要每次重新发明发型、脸型、年龄和服装体系。
- 若有参考图，优先锁定参考图中的身份特征。
- 场景和镜头可以变，但人物身份描述应稳定。

## 8. 参考图改造

用户给照片时，优先提取摄影关系：

- 人物占画面比例
- 视角高低
- 摄影距离
- 可能焦段
- 前景遮挡
- 主光方向
- 色块数量
- 动作是否完成

除非用户要求复刻，否则把摄影关系迁移到新场景，而不是复制原图所有物件。

## 9. Prompt 长度

默认以“足够描述一个完整摄影决策”为准，不追求越长越好。

一组 Prompt 通常控制在约 180-350 个中文字的有效视觉信息范围内即可；复杂系列可更长，但每新增一句都应改变画面，而不是重复修饰。

## 10. 最终判断

一个好的 GPT Image 摄影 Prompt 应该让人能回答：

> 摄影师为什么站在那里，并且为什么恰好在这一秒按下快门？

如果回答不了，继续优化摄影逻辑，而不是继续加风格词。
