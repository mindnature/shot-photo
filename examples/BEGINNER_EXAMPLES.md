# Shot Photo 小白示例库

这页只做一件事：给你可以直接复制的指令。

不会摄影、不会写 Prompt，也可以直接改人物、地点和数量后使用。

---

## 1. 校园随机

```text
$shot-photo
大学生，校园。
随机生成 8 张照片，差异尽量大，给我惊喜。
```

## 7. 小红书九宫格

```text
$shot-photo
给我做一套 9 张小红书写真。
人物：一个中国女生。
地点：广州老城区。
感觉：自然、松弛、真实生活感。
同一个人、同一套衣服、同一个下午。
要有大环境、全身、半身、近景、动作、细节和收尾，不要 9 张一个机位。
```

## 8. 参考图：学拍法

上传一张喜欢的照片后：

```text
$shot-photo
学这张图的拍法，不复制人物、衣服和具体背景。
保留它的摄影距离、观察关系、构图和光线逻辑。
换成一个中国女生，广州夏天，随机生成 6 张。
```

# 出图后怎么继续改

## 太摆拍

```text
太摆拍了。保留人物和场景，动作全部重做，像没有准备好时被拍到。
```

## 人物太大

```text
人物占画面太大。下一轮让环境承担更多叙事，多做小人物大环境。
```

## 机位太普通

```text
这批机位太安全。保留真实感，增加门框后、玻璃后、低机位、远距离和侧后方观察。
```

## 太像 AI

```text
太像 AI 写真。减少完美皮肤和标准姿势，增加真实空间、未完成动作和自然遮挡。
```

## 第 3 张最好

```text
第 3 张最好。我喜欢它的人物距离、构图和光线。
保留这三个特点，其他全部重新随机。
```

## 想更随机

```text
这一轮还是太统一。下一轮不要继承人物、服装、色调和场景，越随机越好。
```
