# Shot Photo 使用示例

## 1. 最简单调用

```text
使用 $shot-photo，生成 6 组。一个短发中国女生，广州盛夏，生活感，9:16。
```

Skill 应先将“生活感”转译成真实动作、观察距离、非中心构图和自然光，而不是直接反复写“生活感、抓拍感、真实感”。

---

## 2. 锁定关键条件

```text
使用 $shot-photo，荷塘、28mm、贴近水面的极低机位，9:16，生成 4 组。其余交给摄影导演。
```

应锁定：

- 荷塘
- 28mm
- 极低机位
- 9:16

不要再加入太多新的硬约束。通过动作、景别、构图、前景与光线制造差异。

---

## 3. 只给模糊情绪

```text
使用 $shot-photo，把“成年人下班后一个人坐在城市里发呆”拍成 6 张照片。
```

推荐优先匹配：`都市疏离` 或 `日常观察`。

不要把“孤独”直接视觉化成夸张悲伤表情；可以通过人物与建筑的尺度、摄影距离、视线方向、大片留白和未完成动作表达。

---

## 4. 同一人物系列

```text
使用 $shot-photo，固定同一位 30 岁左右的短发中国女性：黑色齐耳短发、自然肤质、轻微单眼皮、日常淡妆。生成 8 组广州夏日城市摄影，同一人物身份不要漂移。
```

人物身份描述属于 Hard Anchor。镜头、场景和动作可以变化，但每组 Prompt 都要复用稳定身份特征。

---

## 5. 参考图迁移摄影语言

```text
使用 $shot-photo，分析这张参考图的摄影语言，不复制服装和背景。把同样的摄影关系迁移到广州老城区雨后街头，生成 5 组。
```

应分析：

- 人物占比
- 摄影距离
- 焦段倾向
- 摄影师高度
- 主体位置
- 前景结构
- 主光方向
- 色块关系
- 动作完成度

迁移这些关系，而不是机械复制原图物件。

---

## 6. Python 可复现生成

```bash
python3 scripts/generate.py "一位短发中国女性" \
  --count 6 \
  --intent "广州盛夏，生活感" \
  --profile 东方盛夏 \
  --ratio "9:16 竖幅" \
  --seed 42
```

锁定场景和焦段：

```bash
python3 scripts/generate.py "一位短发中国女性" \
  --count 4 \
  --scene "盛夏荷塘" \
  --lens 28mm \
  --profile 东方盛夏 \
  --seed 7
```

输出 JSON：

```bash
python3 scripts/generate.py "一位短发中国女性" --count 6 --format json
```

脚本用于可复现抽样和测试；在 Codex / ChatGPT 中直接使用 Skill 时，应由模型根据 `SKILL.md` 做更完整的摄影判断，而不是被脚本限制。

---

## 7. 推荐的迭代方式

看到喜欢的摄影作品时，不要只收藏 Prompt。记录：

```text
为什么喜欢：
- 人物很小
- 35mm
- 低机位
- 前景只遮一点
- 光线很硬
- 青绿色块
- 人物没有看镜头
- 动作没有完成
```

然后把这些判断逐步沉淀进 profile、兼容性规则和未来的个人 taste profile。
