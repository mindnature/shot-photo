# Reference Photo Workflow

Shot Photo v0.2 支持把参考照片拆成摄影 DNA，再迁移到新人物、新地点或新叙事。

## 示例一：只学拍法，不复制内容

用户：

```text
使用 $shot-photo，参考我上传的这张照片。不要复制人物和服装，只保留它的摄影关系，换成广州盛夏街头的一位短发中国女生，9:16，给我 4 组。
```

执行：

1. 读取 `references/reference_dna.md`。
2. 提取主体占比、摄影距离、可能焦段、机位高度、构图重心、空间层次、光线几何、瞬间状态。
3. 使用 `structure_transfer`。
4. 锁定 3–5 个 Structural DNA。
5. 用户指定的“短发中国女生、广州盛夏街头、9:16”作为 Hard Anchors。
6. 其余动作、具体前景、局部光线变化继续由摄影导演决定。
7. 生成 4 个同摄影 DNA、但镜头瞬间不同的 GPT Image Prompt。

## 示例二：只要这种氛围

用户：

```text
参考这张图的感觉，但不要照着构图。我要一个人在雨后的老城区散步。
```

执行 `mood_transfer`：

- 分析情绪来自什么，而不是复制构图。
- 优先迁移光线软硬、摄影距离、色块、人物与镜头关系、真实感来源。
- 场景和构图重新设计。

## 示例三：接近复刻

用户：

```text
这张照片的画面关系我很喜欢，尽量保留构图、机位和光线，人物换成我指定的主体。
```

执行 `close_rebuild`：

- 高权重保留主体位置、机位、空间层次、光线和主要色块。
- 不虚构具体 EXIF。
- 新主体身份优先于参考图人物身份。

## 示例四：多图归纳个人风格

用户：

```text
这 6 张都是我喜欢的照片。不要逐张复刻，找出共同摄影语言，形成一个可以长期复用的摄影 profile。
```

执行：

1. 分析每张图片的 Reference DNA。
2. 统计重复出现的摄影关系。
3. 找出高频结构：例如偏 35mm、大留白、人物偏侧、树影硬光、动作未完成、轻微遮挡。
4. 将共同项整理成新的 photographer profile 草案。
5. 低频偶发细节不进入核心 profile。

## 推荐输出

当用户要求分析时：

```text
Reference DNA
- 主体占比：人物约占画面 25%
- 摄影距离：中远距离观察
- 可能焦段：约 50–85mm
- 机位：略低于视线
- 构图：人物位于右下，左侧保留大面积空环境
- 空间层次：近处失焦栏杆 / 人物 / 远处建筑
- 光线：侧逆光，背景更亮，人物略暗
- 色块：灰蓝、米白、肤色
- 瞬间：人物走动中短暂停顿
- 真实感：局部遮挡 + 人物不服务镜头

最值得保留：摄影距离、人物占比、右下重心、侧逆光、未完成动作。
```

最终 GPT Image Prompt 不需要把上面这些字段机械照抄，而应重新组织成自然摄影语言。
